Playwright lab. Browser automation practice repo, not app code.

Stack: Node.js, Playwright, TypeScript, Allure, GitHub Actions.

Root:
- playwright.config.ts: runner config and report setup
- package.json: deps and project metadata
- tsconfig.json: TypeScript config
- user-session.json: saved browser state
- auth/: stored session auth files
- utils/CustomTTAReporter.ts: custom dashboard reporter
- .github/workflows/playwright.yml: CI pipeline

Tests:
- tests/: 12 learning modules + root practice specs
- 01_Basics: basics, annotations, first runs
- 02_First_Tests: browser contexts and pages
- 03_Locators_Commands: CSS, XPath, roles, cookies, key presses
- 04_Session_Storage: session/local storage and auth reuse
- 05_Allure-Reports: Allure steps and reports
- 06_Multiple_Elements: element loops, forms, lists
- 07_WebTables: tables, dropdowns, select boxes
- 08_Frames_iFrames: iframe work
- 09_Keyboard_Hover_Drag_Drop: keyboard, hover, drag/drop, right click
- 10_JS_Alerts: alert, confirm, prompt flows
- 11_Handle_SVG: SVG clicks and map selection
- 12_Shadow_DOMs: shadow DOM access

Root specs:
- example.spec.ts: starter flow
- Cura-Appointment.spec.ts: healthcare app flow
- VWO login and free trial specs: real-site automation
- date-stamped specs: extra practice runs

Outputs:
- playwright-report/, allure-report/, allure-results/, tta-report/, test-results/

Big picture: repo teaches Playwright fundamentals with real websites, selectors, state reuse, and reporting.
